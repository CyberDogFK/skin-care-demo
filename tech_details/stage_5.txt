5.3 Local run instructions (README)
-----------------------------------
- Install Node.js LTS (nodejs.org) and check `node -v`, `npm -v`.
- npm install
- cp .env.example .env   and set VITE_GTM_ID (optional)
- npm run dev            -> http://localhost:5173
- npm run build          -> dist/
- npm run preview        -> test the production build locally


5.4 Deployment — recommended: Netlify (free, HTTPS, SPA-friendly)
-----------------------------------------------------------------
Why public HTTPS matters: Meta Pixel Helper / Events Manager, GA4 and Tag
Assistant work best on a real public URL; teammates can test; same setup as
real sites.

Steps:
1. Push project to a GitHub repository (git init, commit, gh repo create
   or GitHub web UI).
2. Netlify -> Add new site -> Import from GitHub -> choose repo.
3. Build command: npm run build   Publish directory: dist
4. Site settings -> Environment variables: VITE_GTM_ID = GTM-…  -> redeploy.
5. public/_redirects (/*  /index.html  200) makes /product/cream_001 etc.
   work on refresh.
6. Optionally rename the site (glow-care-demo.netlify.app).
7. Add the URL to GTM Preview and to the GA4 data stream / Meta Pixel
   settings where relevant.
Alternative (short note): Netlify Drop — drag the dist/ folder (GTM ID must
be in .env before building). Mention Vercel / GitHub Pages as alternatives
(GitHub Pages needs a base path + 404.html trick -> not recommended for
beginners).
